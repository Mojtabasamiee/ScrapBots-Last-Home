# آهن‌پاره‌بان‌ها: خانه آخر — Scrap Bots: Last Home

بازی استراتژیک دفاع از خط (Lane Defense) دوبعدی برای اندروید، کاملاً فارسی و راست‌به‌چپ.
A 2D Persian RTL lane-defense strategy game for Android. Season One: 20 stages.

## نسخه ۱.۱ — v1.1 (این نسخه)
رفع کامل دو مشکل گزارش‌شده:
- **ابعاد صفحه:** همه صفحات حالا با نسبت ثابت طراحی ۱۶۰۰×۹۰۰ روی هر اندازه و هر نسبت نمایشی، letterbox و بدون کشیدگی رندر می‌شوند؛ در حالت عمودی صفحه «گوشی را بچرخانید» نمایش داده می‌شود.
- **دکمه‌ها:** تمام دکمه‌ها (منوی اصلی، مراحل، گاراژ، تنظیمات، توقف، نوار کارت‌ها، دستگاه اضطراری و…) با سیستم hit-test مختصات طراحی بازنویسی شدند و همگی کار می‌کنند.

## امکانات
- ۲۰ مرحله فصل اول در ۴ منطقه (حیاط، گاراژ، اتاق نشیمن، زیرزمین)
- ۱۲ ربات مدافع ساختنی با قابلیت واقعی و ۳ سطح ارتقا در گاراژ
- ۱۰ نوع دشمن (همه با چرخ‌های متحرک) + باس فصل «نگهبان هسته» با ۳ فاز
- منابع جرقه (درون مرحله) و پیچ‌ومهره (پیشرفت دائمی)
- ذخیره خودکار پیشرفت (localStorage) • موسیقی و صداهای ساختگی (WebAudio)
- رابط کاملاً فارسی با فونت وزیرمتن، حالت انگلیسی هم موجود است

## اجرا
- **وب:** `index.html` را در مرورگر باز کنید (آفلاین کار می‌کند).
- **اندروید:** فایل `release/ScrapBots-LastHome-v1.1.apk` را نصب کنید (Android 5.0 به بالا).

## ساخت از سورس
```bash
# بازی تک‌فایلی (وب)
python3 tools/build_game.py        # خروجی: index.html

# APK اندروید (نیازمند Android SDK build-tools 34 و JDK)
bash tools/build_apk.sh            # خروجی: release/ScrapBots-LastHome-v1.1.apk
```

> هشدار امنیتی: keystore را عمومی نگه ندارید؛ برای انتشار رسمی، این فایل را به‌صورت خصوصی نگه دارید.

## ساختار پروژه
```
src/        سورس بازی (5 ماژول JS + قالب HTML)
index.html  بازی ساخته‌شده تک‌فایلی (فونت وزیرمتن embed شده)
android/    پروژه WebView اندروید (MainActivity + Manifest + آیکون‌ها)
keystore/   کلید امضا
release/    APK نهایی امضاشده
tools/      اسکریپت‌های ساخت
```

## تکنولوژی
Canvas 2D + WebAudio (بدون هیچ وابستگی خارجی) پوشیده‌شده در WebView اندروید.
نسخه‌های قبلی Godot در شاخهٔ تاریخچه نگهداری می‌شوند؛ نسخهٔ فعلی با موتور وب برای ثبات رابط بازنویسی شد.
